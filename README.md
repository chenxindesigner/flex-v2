## 基本測試規則

建議用 A、B、C 三個不同 LINE 帳號測試：

1. A 從卡片內按「名片分享」分享給 B
2. B 點擊卡片內任一追蹤按鈕，建立 A → B
3. B 再從卡片內按「名片分享」分享給 C
4. C 點擊後建立 B → C
5. C 成交只算 B，不算 A

不要用 A → B → A 當主要正式測試流程，以免測試資料形成不具實際意義的往返推薦。
